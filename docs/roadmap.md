# Cybersecurity Learning Roadmap

## Phase 1: Foundations

- Linux filesystem, permissions, processes, pipes, and shell commands
- IPv4, TCP, UDP, DNS, HTTP, TLS, and common network services
- Python and Bash fundamentals
- Git and GitHub workflow

## Phase 2: Web security

- HTTP requests, responses, headers, cookies, and sessions
- Browser developer tools, cURL, and Burp Suite
- Authentication and access control
- SQL injection, XSS, CSRF, SSRF, file upload, and path traversal
- API testing and common server-side vulnerabilities

## Phase 3: Core security disciplines

- Encoding, hashing, symmetric encryption, and public-key cryptography
- File, disk, memory, and network forensics
- x86-64 assembly and static/dynamic analysis
- Memory corruption and introductory binary exploitation

## Phase 4: Practice

- OverTheWire
- PortSwigger Web Security Academy
- PicoCTF
- TryHackMe and other authorized lab platforms
