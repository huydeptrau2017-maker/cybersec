4. Web application security
5. Cryptography
6. Digital forensics
7. Reverse engineering
8. Binary exploitation

See [the detailed roadmap](docs/roadmap.md).

## Repository structure

- `courses/`: structured study notes by subject
- `labs/`: short notes recorded while completing authorized labs
- `walkthroughs/`: complete solutions published only when disclosure is allowed
- `scripts/`: reusable scripts written during practice
- `resources/`: curated books, courses, tools, and references
- `templates/`: templates for consistent notes and walkthroughs

## Legal and ethical use

All security techniques in this repository must only be used on systems that I own or have explicit permission to test. See [the lab safety policy](docs/lab-safety.md).
